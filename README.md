## 02 AIへのインプット・アウトプットの考え方

### まずは試してみましょう（講師デモ）

次の文を、そのままAIに入力してみてください。

```
お客様への返信文を書いて
```

### 情報を足したプロンプト（講師デモ）

スライドの【前提】【素材】【お手本】【制約】【出力】にあたる内容を、普通の文章で書いたものです。

```
あなたは中古ホビーショップの店舗スタッフです。
お客様からLINEで買取の問い合わせが届きました。今日中に返信します。

お客様のメッセージと、当店の買取ルールを貼ります。
お客様：「ポケモンカードを100枚くらい売りたいのですが、スリーブに入れたままでも大丈夫ですか？ 予約は必要でしょうか。土曜の午後に行けそうです。」
当店のルール：
・買取の予約は不要（営業時間中はいつでも受付）
・カードはスリーブに入れたままで大丈夫（査定のときにスタッフが外します）
・100枚以上の場合、査定に30分〜1時間ほどかかる
・本人確認書類（運転免許証など）が必要。18歳未満の方は保護者の同意書も必要
・土日の午後は混み合う
・査定額は、実物を見てからお伝えする

以前の返信の例も貼ります。書き出しとトーンを合わせてください。
「お問い合わせありがとうございます。〇〇店の山田です。ゲーム機の買取についてですね。箱や説明書がなくても買取できます。査定額は実物を拝見してからのご案内になります。ご来店をお待ちしております。」

査定額には触れないでください。ルールにないことは書かないでください。200字程度の、やわらかい丁寧語でお願いします。
LINEにそのまま貼って送れる返信文を1つ作ってください。
```

### 何を渡せばよいか分からないときは

足りない情報を、AIに質問してもらいましょう。〇〇の部分を、お願いしたい作業に置き換えてください。

```
〇〇の作業をお願いしたいです。
良い結果を出すために、足りない情報を質問してください。
```

## 03 ワーク① 業務課題の棚卸し

### インプット・アウトプットシート

スプレッドシート（またはExcel）のA1セルに貼り付けると、列に分かれます。記入例の4行は消してから、ご自身の業務を書いてください。

```
業務	インプット（使う材料）	アウトプット（できあがる物）	頻度・時間	困っていること	AI活用度
買取告知の更新	買取価格表、過去の告知文	店頭POP・告知文	週2回・各30分	毎回ゼロから書いている	◎
中古商品の相場チェック	各サイトの販売価格	買取・販売価格の案	毎日・1時間	見るサイトが多い	○
伝票・データ入力	紙の伝票	Excelの一覧	毎日・40分	転記ミスが起きる	○
景品の発注	在庫表、人気の傾向	発注リスト	週1回・1時間	何を選ぶか迷う	△
```

AI活用度は、◎ そのまま任せられそう／○ 一部なら任せられそう／△ 難しそう、の3段階でつけます。

Excel版のシート（担当別の記入例3パターンつき）は、[生成AI定着ワークショップ_ワーク①.xlsx](生成AI定着ワークショップ_ワーク①.xlsx) からダウンロードできます。

## 04 ワーク② プロンプト作成・実行・改善

### プロンプトの型

スライドのテンプレート（【役割】【前提】【素材】【お手本】【制約】【出力】）を、普通の文章の形にしたものです。（ ）の中をご自身の業務に置き換え、使わない行は消してください。

```
あなたは（役割　例：中古ホビーショップの販促担当）です。
（誰が・何のために・どんな状況で使うか）ので、（作りたいもの）を作ってください。
使う材料はこちらです。
（データ・文章・画像を貼る）
過去にうまくいった例はこちらです。この雰囲気に合わせてください。
（過去の良い例を貼る）
（文字数・表記ルール・使わない表現）を守ってください。
（形式・用途・案の数）で出してください。
```

### 修正のひと言 例

```
もっと短くしてください
```

```
子どもにも伝わる言葉にしてください
```

```
表の形にしてください
```

```
2案目をベースに、見出しだけ変えてください
```

```
足りない情報があれば質問してください
```

## 05 画像生成AIで販促物をつくる

### まずは試してみましょう（講師デモ）

次の文を、そのままAIに入力します。無料版は画像を作れる回数が限られているため、お手元で試すのはワーク③からでも大丈夫です。

```
買取強化のPOPを作って
```

### 情報を足したプロンプト（講師デモ）

スライドの【前提】【素材】【お手本】【制約】【出力】にあたる内容を、普通の文章で書いたものです。

```
あなたは中古ホビーショップの販促担当です。
今週末の「トレーディングカード買取強化キャンペーン」の告知POPを作りたいです。レジ横に掲示し、来店したお客様に見てもらいます。
店名は〇〇店、期間は10月3日（土）・4日（日）、内容は「対象カードの買取価格を通常より10%アップ」です。
前回好評だったPOPの見出しは「眠ってるカード、今が売りどき！」でした。この雰囲気に合わせてください。
見出しは15文字以内、価格は税込表記にしてください。「業界最高値」などの断定表現や、実在のキャラクター・ロゴは使わないでください。
A4縦で印刷する前提で、見出し・本文・注意書きに分けて3案出してください。
```

### 会話で仕上げるときのひと言

3案が1枚のA4にまとめて出力されたときに使います。出力された画像を添付して送ると、意図が伝わりやすくなります。

```
別々のA4で作成してください
```

```
次のデザインもお願いします
```

## 06 ワーク③ 販促物制作

### 画像生成プロンプト集（作例つき）

チラシ・フライヤーの型と作り方（講師デモの作例つき）、ポスター・商品写真・ロゴ・図解などの作例画像つきプロンプト、言い方でどう変わるか（光・カメラ・色味・画風・文字・レイアウトの用語）は、[生成AI定着ワークショップ_ワーク③_画像生成プロンプト集.md](生成AI定着ワークショップ_ワーク③_画像生成プロンプト集.md) にまとめています。

まずは[チラシ用プロンプトの型](生成AI定着ワークショップ_ワーク③_画像生成プロンプト集.md#flyer-template)をコピーし、（ ）の中を自店の内容に置き換えて使ってください。

### 画像を直すときのひと言

1か所だけ直したいときは、同じチャットで「〇〇だけ」と伝え、変えない所も書き添えます。

```
見出しの文字だけ「〇〇」に変えてください。それ以外は変えないでください
```

```
背景の色だけ白にしてください。文字とレイアウトはそのままにしてください
```

直したい点が多いときや、雰囲気を大きく変えたいときは、直したい点をプロンプトに書き足して、新しいチャットで作り直すほうが早く仕上がります。日付・価格などの細かい文字は、Canvaで直すのが確実です。

<a id="flyer-studio"></a>

### 無料版で画像が作れなくなったら

ChatGPTなどの無料版は、画像を数枚つくると上限に達することがあります（事前の検証では5枚ほどでした）。画像が作れなくなったら、Copilot や Gemini に切り替えるか、スタイルアーツの画像生成アプリ「フライヤースタジオ」を使ってください。

**フライヤースタジオ**：https://flyer-studio.style-arts.workers.dev/

- 会場でお伝えする合言葉を入力すると使えます
- [チラシ用プロンプトの型](生成AI定着ワークショップ_ワーク③_画像生成プロンプト集.md#flyer-template)を、そのまま貼り付けて使えます。参考画像は2枚まで添付できます
- 作った画像は、ダウンロードして保存しておきましょう
