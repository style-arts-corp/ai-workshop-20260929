# ai-workshop-2026
生成AIワークショップ2026　参考集

当日「手を動かしてみましょう」と出てきたプロンプトをまとめています。
各ブロックの右上にあるコピーボタンで、そのままコピーできます。

---

## 使うときの3つのルール

1. **ファクトチェック** — 価格・相場・日付は、AIの出力をそのまま使わず必ず確認する
2. **権利侵害** — 実在のキャラクター・他社のロゴ・有名人を生成しない
3. **機密情報** — お客様の氏名・連絡先・査定情報は入力しない

## 【ワーク①】業務課題の棚卸し

自分の1日の業務を書き出して、AIに任せられそうな業務を見つけます。

### シートの形と記入例

| 業務 | インプット（使う材料） | アウトプット（できあがる物） | 頻度・時間 | 困っていること | AI活用度 |
|---|---|---|---|---|---|
| 買取告知の更新 | 買取価格表、過去の告知文 | 店頭POP・告知文 | 週2回・各30分 | 毎回ゼロから書いている | ◎ |
| 中古商品の相場チェック | 各サイトの販売価格 | 買取・販売価格の案 | 毎日・1時間 | 見るサイトが多い | ○ |
| 伝票・データ入力 | 紙の伝票 | Excelの一覧 | 毎日・40分 | 転記ミスが起きる | ○ |
| 景品の発注 | 在庫表、人気の傾向 | 発注リスト | 週1回・1時間 | 何を選ぶか迷う | △ |

AI活用度　◎ そのまま任せられそう　○ 一部なら任せられそう　△ 難しそう
迷ったら「インプット」と「アウトプット」が両方デジタルかどうかで判断すると分かりやすくなります。

### スプレッドシートにそのまま貼れる形

下のブロックを**右上のコピーボタンでコピー**して、スプレッドシート（またはExcel）の **A1セルに貼り付け**てください。自動で列に分かれます。

```
業務	インプット（使う材料）	アウトプット（できあがる物）	頻度・時間	困っていること	AI活用度
買取告知の更新	買取価格表、過去の告知文	店頭POP・告知文	週2回・各30分	毎回ゼロから書いている	◎
中古商品の相場チェック	各サイトの販売価格	買取・販売価格の案	毎日・1時間	見るサイトが多い	○
伝票・データ入力	紙の伝票	Excelの一覧	毎日・40分	転記ミスが起きる	○
景品の発注	在庫表、人気の傾向	発注リスト	週1回・1時間	何を選ぶか迷う	△

```

※ 記入例の4行は消して、自分の業務を書いてください。
※ 列がうまく分かれないときは、貼り付けたあと **データ → テキストを列に分割**（Excelは「区切り位置」）で「タブ」を選んでください。

## 【ワーク③】販促物制作

### 参考：POPの文面をAIに書かせる場合

```
買取強化のPOPを作って
```

↓ 5要素を足したもの

```
あなたは中古ホビーショップの販促担当です。
【前提】今週末の「トレーディングカード買取強化キャンペーン」の告知POPを作りたいです。レジ横に掲示します。
【素材】店名：〇〇店／期間：〇月〇日・〇日／内容：対象カードの買取価格を通常より10%アップ
【お手本】前回好評だったPOPの見出し「眠ってるカード、今が売りどき！」
【制約】見出しは15文字以内。価格は税込表記。「業界最高値」などの断定表現は使わない。
【出力】A4縦で印刷する前提で、見出し・本文・注意書きに分けて3案出してください。
```

### 画像生成のコツ

- **1生成 1チャット**。同じチャットで会話を続けて直すと、前の指示と前の画像の見た目を引き継いでしまい、修正ではなく作り直しに近づきます
- 直したいときは、直した内容を反映した**1本のプロンプトを書き直して、新しいチャットで**出し直す
- どうしても会話で直したいときは、画像を開いて**変えたい場所をブラシで塗ってから**指示する（マスク処理）。塗っていない部分は残ります
- 文字や配置の細かい調整は、AIで粘らずCanvaで直したほうが速い

### 販促物で気をつけること

- 実在のキャラクター・他社のロゴを描かせない（「〇〇風に」も避ける）
- 価格・日付・条件は、掲示前に必ず人が確認する
- 根拠のない「最安」「No.1」は使わない
- 公式画像を使う・加工するときは利用条件を確認する

## 【共通】制限が来たときの代替ツール

| 用途 | 通常 | 制限が来たら |
|---|---|---|
| 文章・表 | ChatGPT | Gemini／Copilot／Claude |
| 画像生成 | ChatGPT | Canvaのマジック生成／Gemini（Nano Banana Pro） |

無料プランは画像生成の回数制限が早く来ます。制限が出たら、待たずに上の代替へ移って作業を続けてください。
