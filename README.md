# ai-workshop-2026
生成AIワークショップ2026　プロンプト集
当日「手を動かしてみましょう」と出てきたプロンプトをまとめています。
各ブロックの右上にあるコピーボタンで、そのままコピーできます。

〇〇の部分は、ご自身の店舗名・商品名・日付に置き換えてください。

---

## 使うときの3つのルール

1. **ファクトチェック** — 価格・相場・日付は、AIの出力をそのまま使わず必ず確認する
2. **権利侵害** — 実在のキャラクター・他社のロゴ・有名人を生成しない
3. **機密情報** — お客様の氏名・連絡先・査定情報は入力しない

---

## 1. まずはやってみよう（考え方講座）

考えずに、このまま入力してみてください。

```
買取強化のPOPを作って
```

---

## 2. 情報を足したプロンプト（改善後）

同じ依頼に、前提・素材・お手本・制約を足したものです。

```
あなたは中古ホビーショップの販促担当です。

【前提】今週末の「トレーディングカード買取強化キャンペーン」の告知POPを作りたいです。レジ横に掲示し、来店したお客様に見てもらいます。

【素材】店名：〇〇店／期間：〇月〇日（土）・〇日（日）／内容：対象カードの買取価格を通常より10%アップ

【お手本】前回好評だったPOPの見出し「眠ってるカード、今が売りどき！」

【制約】見出しは15文字以内。価格は税込表記。「業界最高値」などの断定表現は使わない。

【出力】A4縦で印刷する前提で、見出し・本文・注意書きに分けて3案出してください。
```

## 3. 何を渡せばいいか分からないときの1本

```
いい結果を出すために、足りない情報を質問してください。
```

## 4. プロンプトの型（ワーク②で使います）

括弧の中を、ご自身の業務に置き換えてください。

```
あなたは【役割】です。

【前提】誰が・何のために・どんな状況で
【素材】データ・文章・画像をここに貼る
【お手本】過去の良い例があれば
【制約】文字数・表記ルール・NG表現
【出力】形式・用途・案の数
```

## 6. 活用例A 告知ポスターをつくる（ワーク③）

ChatGPTにCanvaのデザインまで作ってもらいます。

```
Canvaで、トレカの新弾予約の告知ポスターをA4縦で作ってください。
テーマは「サイバー・近未来」、色は青と紫。競技プレイヤーに響くキャッチコピーも考えて入れてください。
入れる情報：予約開始日〇月〇日／発売日〇月〇日／店名〇〇店
実在のゲームのキャラクターやロゴは使わないでください。
```

出てきたら「Canvaで編集」を押して、崩れた文字を直し、商品写真を入れて仕上げます。

---

## 7. 活用例B 買取表・価格POPのひな形をつくる（ワーク③）

ひな形を1枚つくれば、あとは毎回データを差し替えるだけです。

```
Canvaで、トレカの買取POPのひな形をA6縦で作ってください。
「買取強化中」の見出しと、商品名・レアリティ・型番・買取価格を入れる場所を用意してください。
商品名・レアリティ・型番・価格は、それぞれ別のテキストとして分けてください。
中身は仮の文字で構いません。
```

**Canvaでの続き**

- 無料プラン：ページを複製して、手元のデータを見ながら商品名と価格を打ち替える
- Canvaプロ：アプリ「一括作成」に手元のデータ（CSV・Excel）を読み込み、テキストと列をつなぐ

価格は必ず、ご自身のリストと照合してから掲示してください。

---

## 8. 手元のデータを整えたいとき

表記がバラバラなリストを、そのまま使える形に整えます。

```
以下のリストを、Canvaの一括作成で使えるように、
【商品名, レアリティ, 型番, 買取価格】のカンマ区切り（CSV形式）で出力してください。

・価格は数字のみ（カンマや「円」は入れない）
・1行目は見出し行にする
・備考は含めない

（ここにご自身のリストを貼る）
```

価格を勝手に書き換えていないか、必ず元のデータと見比べてください。

---

## 制限が来たときは

無料プランでは、途中で回数制限がかかることがあります。

- 文章づくりで止まったら → Gemini や Copilot に移る
- 画像で止まったら → Canvaのマジック生成を使う

切り替えながら進めれば問題ありません。
